# TP-JS-EstructurasControl-Colque

## Trabajo Práctico N°1

Trabajo práctico realizado en JavaScript sobre estructuras condicionales,
entrada de datos mediante prompt(), salida mediante alert() y console.log(),
y utilización de switch.

## Ejercicios

1. Control de Acceso y Gestión de Permisos por Rol
2. Cotizador Dinámico de Pólizas de Seguro Automotor
3. Calculadora de Liquidación de Sueldos
4. Tarificador Dinámico de Plataforma de Transporte
5. Evaluador de Categoría Tributaria
6. Scoring Crediticio
7. Cajero Automático Multiopción
8. Motor de Descuentos en Comercio Electrónico
9. Sistema de Triaje para Urgencias Médicas
10. Conversor Monetario

## Tecnologías utilizadas

- HTML5
- JavaScript
- Visual Studio Code
